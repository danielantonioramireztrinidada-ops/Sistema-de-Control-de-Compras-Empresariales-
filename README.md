# Sistema de Control de Compras Empresariales

**Autor:** Daniel Antonio Ramírez Trinidad

## Descripción
Sistema para gestionar solicitudes de compra, productos, proveedores y órdenes de compra dentro de una empresa.

## Objetivo
Organizar y controlar el proceso de compras empresariales, registrando estados, cantidades y costos mediante una base de datos.

## Clases principales
- SolicitudCompra
- Producto
- Proveedor
- OrdenCompra

## Funcionalidades previstas
- Registro y seguimiento de solicitudes de compra.
- Gestión de productos y cantidades disponibles.
- Registro y consulta de proveedores.
- Creación y seguimiento de órdenes de compra.
- Control de estados y costos.

Los requerimientos iniciales del proyecto están documentados en los Issues de este repositorio.
